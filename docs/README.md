# Documentation map and authority

Updated 2026-10-09. Current root source is authoritative for implementation. A document date, exported interface or historical PASS is not proof that a newly built runtime passes the same contract.

| Role | Authority |
| --- | --- |
| Entry/build and supported workflow | [Root README](../README.md), [development](DEVELOPMENT.md), [runtime staging](../graphics-translator/RUNTIME.ko.md) |
| Current support and qualified evidence | [CORE](../graphics-translator/CORE-IMPLEMENTATION-STATUS.ko.md) |
| Remaining implementation and verification | [PRIORITIES](../graphics-translator/IMPLEMENTATION-PRIORITIES.ko.md) |
| Current review, designs, fixes and new verification | [2026-10-07 review ledger](D3D12-REVIEW-AND-DESIGN-2026-10-07.md) |
| Native architecture/build/guest execution boundaries | [ARM64/FEX](ARM64-FEX-IMPLEMENTATION.md) |
| Public API, resources, format and synchronization contracts | Contract documents linked from README; their dated fixture results retain their original scope |
| Fixture build/run procedure | [SMOKE](../graphics-translator/SMOKE-TEST.ko.md), NGX/temporal test guides; generic runner and native FEX observer are distinct |
| Relevant earlier results and closed review findings | [Evidence index](../graphics-translator/IMPLEMENTATION-HISTORY.ko.md); session handoffs and duplicate status snapshots are removed |
| Frozen import/legal provenance | graphics-translator upstream lock and historical patches, docs/provenance, licenses and third-party notices; not regenerated by current development |

History indexes dated observations and qualified limits, not old session instructions or repeated status tables. Disk cleanup removed many historical logs/results as well as runtime payloads. The [evidence index](../graphics-translator/IMPLEMENTATION-HISTORY.ko.md#증거를-읽는-기준) distinguishes the currently available ZZZ records from historical citations. The documentation check reports unavailable local evidence separately instead of treating it as a missing source link.

Licenses, copyright notices and the frozen source-import manifest remain intact; its original file hashes describe the import baseline, not the current file inventory.

Run `python3 -B scripts/test-owned-documentation.py` from a clean source checkout without local `.omo/` session state. This checks local document/source links in the root, docs and graphics-translator directories, and absence of agent state; it does not check archived handoff integrity or GPU/API conformance. An active local `.omo/` directory fails the latter check even when links pass. Session state, frame captures and build outputs are not part of the source commits.
