### Confirmed gap: internal resolve native-PSO reuse

**Reference behavior.** `MPLContext::GetResolvePipeline`, offset `0x3248c`, Evidence **`ev_7eeedd9f1c3411ed3e2d9ab947fd455fe672687e8f2424d9251dbfa1ddc0425b`**, performs a locked lookup by `ResolvePSOKey`; a non-null entry skips descriptor/function creation and native pipeline compilation. On miss it selects the float/integer/depth/stencil function, creates the native render pipeline and stores it. `ReplayResolve`, offset `0x35689`, Evidence **`ev_5671a2e51974562f4f9788ba05f0b4be8d01f7c93b129bdd4984427e29d5a34b`**, calls that helper then binds the returned pipeline. The older MTL path independently has a pixel-format keyed retained cache in `D3DMDevice::GetResolveSubresourceRegionPipeline`, offset `0x552bc`, Evidence **`ev_b750ce453a6b9f5c0c301c0ea2db80078754f1c7d6f8c484e419d074ecc3aaff`**; its call site is `EncodeResolveSubresourceRegion`, `0x15c579`, Evidence **`ev_d2d8db98717865f0208c3f7fbc5f1eb1abd5ff03d628d6fae554381a753247d8`**.

**Exact owned counterpart.** `src/d3d12/d3d12_command_list.cpp:9553-9589` branches on `!whole_average`, creates vertex/fragment function descriptors and unconditionally calls `newRenderPipelineState` at **`:9589`**. The depth/stencil state is also constructed at `:9591-9607`. `src/winemetal/Metal4Pipeline.hpp:82-89` is a direct WMT call; `src/winemetal/unix/winemetal_metal4_pipeline.c:98-125` builds a descriptor and calls the native compiler every time. There is no generic wrapper cache hiding this work. CacheParity independently confirmed the same boundary. Existing shader-stage/native-library/function-specialization ports do not cache these internal resolve PSOs.

**Actual path relevance.** This is reachable from public `ResolveSubresourceRegion` (`:9397`) and render-pass ending resolves (`EndRenderPass`, `:10173-10180`). A cropped color resolve, min/max depth/stencil resolve, decompress copy, or predicated average takes this path, even if the same pipeline configuration was recorded earlier. Existing fixtures issue those calls repeatedly (`owned-d3d12-copy-resolve.cpp:324-329`, `:391-398`; multisample include `:383-448`). Games using MSAA depth reduction or subrect/render-pass resolves would encounter this recording-time work. No selected-game trace or frequency measurement was collected; a named game benefit and FPS gain remain unknown. Full-surface unpredicated average generally uses the existing native fast path and is not the optimization target.

**Minimal independent implementation.** Retain the small set of internal resolve pipelines per device, keyed by actual attachment format, selected fragment kind (including single-sample variants), destination plane/type and raster sample count. Keep source/destination rectangles, predicate values and min/max/average parameters outside the PSO key because those are runtime parameters in the owned implementation. Return retained references so recorded command lists keep their current lifetime guarantees. Preserve error handling; do not cache failed creations. Reuse depth/stencil states alongside those finite variants if practical. Do not introduce a broad application PSO cache or change resolve algorithms. A list-local retained cache is a smaller initial alternative, but would leave duplicate first creation across lists.

**Focused validation command after implementation:**

```sh
python3 scripts/test-owned-graphics.py --runtime "$RUNTIME" --fixture "$COPY_RESOLVE_FIXTURE" --suite copy-resolve --mode no-present --validation --out "$QA_OUT/resolve-cache"
```

The variables must name a freshly staged runtime, built existing copy-resolve fixture and fresh output directory. Extend the existing fixture with repeated same-key resolves, distinct format/plane/single-vs-MSAA variants, owner release/reset/replay, and instrumentation asserting one native creation per retained key after warm-up. The existing numeric/sentinel readback must remain exact. Run `multisample-capabilities` with its existing fixture for programmable/decompress/integer coverage. Neither command was run in this read-only phase.
