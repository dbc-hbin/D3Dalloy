# Design specification
Lane: no-format. QA tier: light. Promised format: post (Markdown answer), backed by SYNTHESIS.md.
Audience: Korean project owner. Destination: chat and repository evidence. Answered_by: request/default.
Structure: conclusion, latest run identity, DLSS findings, ranked performance improvements, unresolved evidence, sources.
Citations: [Source N], exact local paths and line ranges. No unsupported numbers or causal claims.
Typography: native Markdown, system sans-serif for optional render. No emoji, no decorative assets.
Figures: textual source-backed flow diagram; tabular counts are sourced from verification output, not FPS estimates.
Gate: static citation/path/claim check plus one Markdown render check. Layout/paginated checks not applicable to a post.
